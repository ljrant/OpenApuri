AVOIMEN LÄHDEKOODIN WILMA-TYÖKALUT

Opintoseuranta, OpiskelijaHaku ja viestityökalut samassa kokonaisuudessa.

OpenApuri lisää tietokoneen Wilmaan yhtenäisen sivupaneelin, ryhmänohjaajan arviointinäkymän, OpiskelijaHaun sekä viestipohjien ja luonnosten hallinnan. Kaikki moduulit sisältyvät yhteen OpenApuri-asennukseen, ja niitä hallitaan ohjelman omista asetuksista.

Työkalut

Ryhmänohjaajan arviointinäkymä

Kerää opiskelijoiden suoritukset samaan matriisiin. Lukuvuosirajaukset, värikoodatut arvosanat, Huomiot-näkymä ja CSV-vienti.

OpiskelijaHaku

Hae opiskelijoiden työjärjestyksistä opintojaksot ja opettajat valitulla ajanjaksolla. Valmistele Wilma-viesti opiskelijoille tai opettajille.

Wilma-sivupaneeli

Yhtenäinen käyttöliittymä eri Wilma-sivuilla. Ohjausryhmän pikalinkit, opiskelijalistan kopiointi ja ryhmien viestikuvakkeet.

Viestipohjat ja luonnokset

Luo viestipohjia, valitse huomiota vaativia opiskelijoita ja hallitse viestiluonnosten paikallista tallennusta.

Yksi OpenApuri-asennus

OpenApuri v1.0.2

Yksi Tampermonkey-skripti sisältää työkalupalkin, ryhmänohjaajan opintoseurannan, OpiskelijaHaun sekä Chromen ja Firefox Androidin viestiluonnostoiminnot. Kytke moduulit päälle tai pois OpenApurin kuvakkeen asetuksista.

Asenna OpenApuri

Mukana olevat moduulit

Työkalupalkki · Opintoseuranta · OpiskelijaHaku · Viestiluonnokset (Chrome) · Viestiluonnokset (Firefox Android)

Jos olet asentanut aiemmat erilliset skriptit, poista ne käytöstä Tampermonkeyssa kerran päällekkäisen toiminnan estämiseksi. Jatkossa vain OpenApuri tarvitsee olla päällä.

Asennus ja tietosuoja

  1. Asenna Tampermonkey.
  2. Asenna OpenApuri ja haluamasi työkalumoduulit yllä olevista linkeistä.
  3. Kirjaudu Wilmaan ja avaa käyttämäsi työkalu. Tarkista tiedot ja vastaanottajat ennen käyttöä.

Arvosanat käsitellään paikallisesti selainistunnossa. Viestipohjat ja luonnokset voivat säilyä selaimen localStorage-muistissa ilman salausta. Wilma voi lisätä opintosuorituksia dynaamisesti ”Näytä kaikki” -toiminnolla, joten tarkista kerättyjen tietojen kattavuus. Käytä vain tietoja, joiden käsittelyyn sinulla on oikeus.

OPEN-SOURCE WILMA BROWSER TOOLS

Course progress, OpiskelijaHaku and messaging tools in one place.

OpenApuri provides a unified desktop sidebar, homeroom course progress, OpiskelijaHaku for timetable courses and teachers, message templates and locally saved drafts. Install OpenApuri once and manage all modules from its built-in settings.

Install OpenApuriInstall OpenApuriGitHub source

Features

Homeroom course progress

Colour-coded course matrix, academic-year filters, issues view and CSV export.

OpiskelijaHaku

Find students, courses and teachers from Wilma timetables across a selected date range. Prepare messages using Wilma.

Desktop sidebar

Consistent tools across Wilma pages, homeroom shortcuts, student-list copying and group-message icons.

Templates and drafts

Save message templates, select students with concerning grades and manage locally stored drafts.

One OpenApuri installation

OpenApuri v1.0.2

One userscript bundles the toolbar, homeroom course progress, student and staff search, and desktop Chrome / Android Firefox draft modules. Manage modules in OpenApuri's in-app settings.

Install OpenApuri

Included modules

Toolbar · Course progress · OpiskelijaHaku · Message drafts (Chrome) · Message drafts (Firefox Android)

If you previously installed individual scripts, disable them once in Tampermonkey to avoid duplicate execution. Keep only OpenApuri enabled afterwards.

Privacy and installation

  1. Install Tampermonkey.
  2. Install only OpenApuri from the link above. Disable older individual scripts to prevent duplicates.
  3. Open Wilma and verify the information and recipients before taking action.

Grades are processed in your browser session. Drafts and templates can persist unencrypted in localStorage. Wilma may load additional course rows dynamically, so verify completeness. Only use student information you are authorized to access.
